# Для Миши

Минимум перед стартом:
1. ПК с уже установленными Node/npm и Codex.
2. Создай пустую папку `DKW_UI_INTERACTION_LAB`.
3. Распакуй туда ZIP.
4. Открой папку в Codex и скажи:
   **«Прочитай START_HERE_CODEX.md и выполни инструкции. Не фиксируй экспериментальные interaction-константы без согласования.»**

Заранее НЕ нужны: собственный домен, OpenAI API key для стенда, база данных, backend или GitHub.

Для первого теста цель — быстрее получить обычную HTTPS-ссылку и открыть её настоящим пальцем на iPhone/Android/Windows Touch. Постоянный Git/deployment/custom domain можно добавить позже.

Первая задача стенда — не угадать “правильные” Ratio/Clamps, а создать измеряемое место, где мы их найдём на реальных устройствах.
